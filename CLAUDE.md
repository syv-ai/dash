# CLAUDE.md

Electron app that runs Claude Code across projects, each task in its own git worktree. Renderer hot-reloads; main-process changes need a restart.

- **Native modules** (`better-sqlite3`, `node-pty`) must be built for Electron's Node ABI. `pnpm install` does it (postinstall runs `pnpm run rebuild`); run `pnpm run rebuild` yourself only if something else rebuilt them. Never bare `pnpm rebuild` or `npm rebuild`: those are the package managers' own commands, which build for plain Node and break dev and `pnpm test` (which runs vitest under Electron's Node).
- **Data folders**: a dev run (unpackaged) uses `~/Library/Application Support/Dash-dev/`, the installed app `~/Library/Application Support/Dash/` (`app.db` there). A fresh dev folder starts with an empty DB; for real data, copy it over with `sqlite3 <Dash>/app.db ".backup '<Dash-dev>/app.db'"` (WAL mode: a plain `cp` while Dash runs can miss writes). A second dev instance beside the first: set `DASH_USER_DATA_DIR` (its own data dir) and `DASH_DEV_URL` (its Vite port).
- **Path aliases**: main's `entry.ts` rewrites `@shared/*` → `dist/main/shared/*` and `@/*` → `dist/main/main/*` at runtime.
- **Styling**: role tokens in `src/renderer/index.css` are the source of truth (`ground`, `well`, `raised`, `line`, `ink`/`ink-2`/`ink-3`, `hover`, `select`, `btn`); the shadcn names (`background`, `muted-foreground`, …) are aliases until call sites move over. Colour means agent state only (`state-needs`/`-fail`/`-work`/`-done`); everything else is neutral, HSL tokens only; for faded text prefer `ink-2`/`ink-3` over `text-*-fade-N`. One font family: system sans for all UI text, branch names, paths, shas, versions and counts included (`tabular-nums` where numbers align); `font-mono` only where the text is code (editor, terminals, code blocks and inline code, scripts, command output). Five text sizes (`text-xs` 11 · `sm` 12 · `base` 13 · `lg` 16 · `xl` 20) and five radii (`rounded-sm` 4 badges · `md` 7 controls · `lg` 8 rows/menus · `xl` 12 sheets · `2xl` 14 dialogs); no `text-[…px]`. Text that names something takes a type role (D38, `index.css`): `type-title` (dialog/page titles), `type-heading` (section headings), `type-subheading` (group labels), `type-label` (key columns, field labels), `type-body`, `type-caption`; each fixes size, weight and ink, so don't hand-assemble `text-sm font-medium text-ink-2` or add a colour beside one. Join classes with `cn()` (`lib/cn.ts`). Use the `components/ui/` primitives, not raw `<button>`/`<input>`; `@shadcn/lint` warns on arbitrary values, raw colours and inline styles outside `ui/`. Icons: lucide-react, 14px, stroke-width 1.8.
- **Zustand**: a selector returning a derived array/object needs `useShallow`, or it re-renders forever.
